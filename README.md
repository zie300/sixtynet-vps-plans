## 线路成色：AS9929、CN2 GIA、163 分别是什么

国内访问美国西海岸，走的骨干网决定晚高峰会不会卡。几个名词先对齐：

- **163 骨干网**：节点以 202.97 开头，用的人多、优化程度低，出国方向容易拥堵和丢包，2021 年扩容后体验有所改善。
- **CN2 GT**：CN2 的中端产品，去程或回程仍可能出现 202.97 节点，晚高峰有拥堵可能。
- **CN2 GIA**：CN2 的高端产品，路由基本全程走 59.43 节点，拥堵少，价格最贵。
- **AS9929**：原网通骨干网，现在是联通第二大网，属于优化线路。

SixtyNet 洛杉矶中国联通 Premium 那组标的是 AS9929，支持免费配置 BGP 会话、95 计费、100M 基础网络带 3 倍突发。第三方在 2025 年 10 月对同机房住宅 IP 机器的路由实测结果是：电信去程走 CN2 直连洛杉矶，联通回程走 AS10099＋AS9929，移动回程走 CN2，三网平均延迟 170–180ms，电信最低约 165ms。这套组合不是双向 CN2 GIA，属于“去程直连＋回程优化”的常见做法。

延迟数字只能当参考。同样一台机器，不同宽带服务商、不同时段、不同本地出口，测出来能差几十毫秒，ICMP 通不通也说明不了 TCP 的实际表现，个别商家 ICMP 和 TCP 还走不同路由。真要判断，下单前 ping 一下官方测试 IP，拿到机器后在自己常用网络下跑一遍晚高峰。

判断一家 VPS 商家值不值得托付几年，业内相对务实的三条门槛是：稳定经营一年以上、没有跑路记录、自己实际使用超过半年。前两条查得到，第三条只能靠时间。

## 多数人其实用不上的两样东西

**住宅 IP 属性。** 它解决的是“平台认为你是真人家庭宽带”这个问题，做 TikTok、Netflix 这类流媒体解锁，或者跨境电商、社媒多账号运营才有意义。个人博客、API 服务、Telegram bot 用普通数据中心 IP 完全够，多付的钱买不到对应收益。而且这类产品还有上面说的端口和探测限制。

**8 核 16G 以上的大配置。** 一个静态站加一个 bot，2 核 2G 就跑得很稳。真到了需要 8 核的负载，通常也该考虑拆分部署而不是把鸡蛋放一台机器上。BGP 会话、95 计费这些功能是给自带 IP 段的用户准备的，普通用户用不到。
